## 操作引導回修（使用者實際回饋）

後續使用者回報：做一下就卡住、不知道下一步，停用按鈕也沒有回應。
先前「UI 好多了」只支持清晰度改善，不能當成完整可用性通過。

程式及控制器檢查確認：

- `refresh_actions` 只有 enabled／disabled，未提供原因或下一步。
- 檔案及貼上文字匯入後未自動選取；分析又要求選取來源，形成未說明的額外門檻。
- 模型 metadata 已保存不代表本次金鑰存在；原介面沒有區分這兩種狀態。
- 版本、來源管理、證據及 Handler 重用在一開始就佔據操作區，小視窗更難辨認主線。

回修保留既有三欄與所有服務契約：

- 上方只有一個主要「下一步」，依缺少欄位、保存、來源、模型、候選、案例、試做及核准狀態切換。
- 灰色按鈕保留原阻擋條件，滑鼠點擊改顯示原因；程式呼叫按鈕也會重核條件，不能借說明繞過核准。
- 檔案、資料夾及文字匯入後選取新來源並預覽；第一次貼文字帶入已保存目標，由使用者補充後明確匯入。
- 來源替換／移除／資料夾比對依當前選取，不使用舊預覽 ID；背景比對固定來源 ID，資料夾替換使用資料夾選擇器。
- 無候選的案例提醒補齊資料，不反覆推薦相同的空比對；模型未設定與缺少本次金鑰分別說明。
- 進階操作預設收合，沒有候選／流程時隱藏不適用的控制；各欄溢出時可捲動，鍵盤焦點帶入可見範圍。
- 目標欄位的 Tab／Shift-Tab 切換焦點，Enter 仍保留多行輸入；試做、外傳與發布確認維持原邊界。

本機不重開或操作使用者已停止控制的 Windows 視窗，可能未保存的輸入保留。
