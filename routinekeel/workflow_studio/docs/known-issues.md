## 支援參數與限制

| 範圍 | 目前邊界 |
|---|---|
| Compiler | 單一檔案輸入、目前受控工具與有界資料 Handler；不支援的 IR 會拒絕，不自動改寫語意 |
| 來源 | 格式／大小／檔案數限制見 source-formats.md；PDF、Office、SVG 不接受 |
| 圖片 | 靜態圖片分析已接線；合成方塊圖測試不證明真實手寫辨識品質 |
| 影片 | P2 實驗功能預設停用；缺少 FFmpeg／ffprobe 時工程測試會跳過，不能算通過 |
| 模型修復 | 最多兩輪；目前 UTF-8 案例，單案例輸入加預期 128 KB、整體準備內容 256 KB |
| 生成程式 | 受限 AST 資料語言；不能 import 任意 Python 套件，配額不是 OS RSS 沙箱 |
| Handler 工具庫 | 同工作區跨專案重用；未提供跨工作區模板交換包 |
| 歷史刪除 | 軟刪除／封存保留來源與歷史，沒有物理清除功能 |
| CLI | ui、projects、status；完整操作目前使用本機服務或圖形工作台 |
| 正式安裝 | 開發入口存在，正式發行包、乾淨安裝與啟動仍待驗收 |

## 驗收回應的解讀

工程 fixture 只證明固定輸入的程式行為。20 件固定案例全部備妥，仍未取得至少 16 件
非技術使用者完成、文字／Mermaid 真實模型各五件、真實手寫品質的結果。
已檢視過的 Windows 主畫面不代表後續所有新增表單、Mac Finder 或其他平台 GUI 已驗收。
三項原生 GUI 測試排除及六項缺少 FFmpeg 的 CI skip，都不列為功能通過。

Example：下列錯誤表示不能使用當前候選發布，不能把 ok=false 改成成功再繼續：

```json
{"ok": false, "error": {"code": "TEST_FAILED", "message": "實際成果與固定成功案例不符。"}}
```

## 錯誤處理與未完成工作

中斷、例外或事件提交失敗不能變成有效完成狀態；有 started 而無完成事件不代表成功。
強制終止程序後，未登錄的建置資料夾保留供診斷，不會自動安裝或補造成功紀錄。
發布中斷另有[核對與恢復程序](release-recovery.md)，不能靠刪掉鎖檔或 journal 解決。

仍須收齊最新 CI、核對全部 AC、完成正式打包、乾淨安裝、操作走查與升級回滾演練。
遇到問題請提供版本、錯誤代碼、操作與已去除敏感內容的最小案例；原始來源、金鑰及整個
console.log 不應直接貼到公開 issue。資料保存及外傳邊界見[隱私與用量](privacy-and-model-usage.md)。
