# 來源匯入與預覽

目前由 `StudioService.sources` 提供本機匯入，不呼叫模型或自動上傳。

| 格式 | 實際預覽與限制 |
|---|---|
| UTF-8 txt、md、json、csv、tsv、log、py、yaml、yml | 純文字預覽，最多 8000 字並標示截斷；不執行程式或渲染 HTML；JSON 需有效 |
| mmd、mermaid | graph／flowchart 的方向、具名節點、方括號／菱形標籤、箭頭與條件；不支援語法報行號 |
| PNG、JPEG、WebP | Pillow 實際解碼驗證、原始像素比例；`fit_size` 提供等比顯示尺寸 |
| 資料夾 | 每項檔案的相對位置、SHA-256、大小與內容預覽；可按相對路徑呈現樹狀清單 |
| ZIP | 同資料夾清單，在記憶體受限讀取；不解壓到原始資料或正式工作區 |

預設最多 1000 檔，單檔 10 MiB、合計 50 MiB、圖片 2000 萬像素，ZIP 膨脹比例最多 100。
拒絕路徑穿越、保留裝置名、大小寫衝突、符號連結／junction、特殊檔、加密 ZIP、
巢狀壓縮檔及無法預覽的格式。PDF／Office／SVG 不接受；一般圖片／資料夾入口也不接受影片。
影片僅由另行啟用的 P2 實驗入口處理，預設停用，見 [影片實驗功能](video-experimental.md)。
格式限制會明確報錯，不能把檔案清單當成已完成內容理解。

`import_text`／`import_path` 建立來源；指定 `source_id` 建立替換版本；`describe`
更新說明並新增版本；`remove` 解除當前來源關聯。這些操作皆使用 Project 預期版本。
`get(..., version=N)` 及 `content(..., version=N)` 可以取得歷史來源，且必須符合專案作用域。
工作臺的「編輯來源說明」在進階來源管理中提供 `describe` 操作，最多 8000 字，綁定開啟表單時的專案版本；
不是每次儲存都偷偷改用最新版本。失敗不清除表單草稿或舊的本機接受狀態；成功後需重新建置／試做／核准。
相同快照重複匯入會回傳既有來源；相同內容以 SHA-256 去重。

為讓來源副本、預覽與指標能在同一交易提交，初版將受限大小的來源內容存為 SQLite BLOB，
不是散落的來源路徑；不修改原始檔。版本 manifest 保存邏輯檔名，不保存原機器絕對路徑。
移除後保留已提交版本，避免破壞證據歷史；目前不提供物理清除歷史的功能。
所有內容均保持本機，來源文字不具有工具授權效力。
