# 手繪圖片與文字一起分析

一般「AI 整理選取來源」現在可接受靜態 PNG、JPEG、WebP，包含手繪節點、標籤與箭頭。
也可選取含圖片與文字／Mermaid 的來源資料夾；服務支援明確選取多份來源。
只送出選取範圍，未選取的其他來源不會自動混入。

外部模型送出前會開啟範圍確認視窗，逐項列出檔名、版本與圖片尺寸，並可預覽真正準備送出的文字及圖片。
工作目標、已允許的工具說明及相關本機關係比對／決策也會送出。取消不發出模型請求。
來源、專案、模型、目的端、費率或圖片預留量改變後，舊的確認範圍失效。

圖片在本機校正 EXIF 方向、移除額外 metadata，再以 PNG 傳送；不縮圖、不裁切，
保留完整解析度與透明度，16-bit 灰階不會因轉 RGB 而截斷。原始來源 bytes 保持不變。
影像中的可見文字仍會傳送，請先在預覽確認來源範圍。動畫／多格圖片拒絕分析，
不會把第一格當成完整來源；影片仍走獨立 P2 實驗功能，預設停用。

模型以供應的圖片檔名引用證據，也可以用 `檔名:region=x,y,width,height` 指定校正方向後的區域，
座標為 0–1 的比例。不能引用不存在的圖片、虛構文字行號、非有限數字或圖片外的區域。
字跡、方向或步驟不明時應提出問題；帶問題或矛盾的候選保存為 `needs_clarification` 草稿，
保留原提案供釐清，不能直接編譯或發布。來源中的指令不授予任何工具或執行權限。

模型輸出持續串流；斷線保留上一個有效版本。結構修正最多兩輪，沿用相同圖片與來源範圍，
每輪仍經預算與授權檢查，不會在圖片失敗後偷偷改成只看文字。

「模型設定 → 圖片與執行期」可調整每張圖片的輸入 Tokens 預留，預設 65,536。
這是可調的本機估計值，不是任何供應商公布的固定 Token 數或帳單上限；
請選擇支援圖片的模型並依其計價調整。每次請求預留文字估算＋每張圖片預留＋輸出上限，
不把壓縮 PNG 或 base64 字數直接當成視覺 Tokens。收到有效 usage 後按實際回報結算；
缺少用量時保留預留額，超出剩餘預算則阻擋下一次呼叫。

現有來源匯入上限仍適用；單次請求最多 32 MiB、文字部分最多 256,000 bytes。
超限會要求縮小選取範圍，不會自行犧牲圖片可讀性。圖片準備在背景工作完成後才開啟確認視窗。

沿用 v014 schema，新增可選的圖片用量設定；舊專案使用預設值。備份仍包含 DB 與 projects 的來源副本。
如需回退程式，先保留最新資料，並用新版設定移除新增選項或使用升級前的設定備份，
避免舊版設定驗證器不認得新欄位；不得覆寫來源或刪除已保存提案。

目前已驗證來源處理、傳送格式、串流、拒絕路徑及 fixture 候選的真正 Runtime 試做。
這不等於真實模型能正確辨識手寫內容；辨識品質、非技術使用者驗收及新增視窗實機走查仍待完成。
