## 狀態與揭露

| 步驟 | 本頁必要內容 | 繼續條件 |
|---|---|---|
| 工作目標 | 名稱、工作、成功條件；可保存草稿 | 至少名稱；先保存，再加入來源 |
| 加入來源 | 三種匯入入口、已加入清單、唯讀預覽及分析問題 | 有候選或已保存流程後前往確認 |
| 確認流程 | 候選選擇、唯讀候選圖；採用後的編輯入口 | 已採用流程及必要目標完整 |
| 試做 | 案例、實際報告、必要時的修復 | 當前版本通過試做 |
| 發布 | 核准者、明確成果確認、本機發布位置 | 原有驗證／核准／指紋條件全部成立 |
