# 本機 Ollama 校稿工具

校稿工具 0.2.0 接受底座領取時產生的 `model_budget`，以每 4 段一批處理完整輸入。宿主使用 `observe_course_host.py --claimed-dispatch` 時，傳入完整的領取輸出，而非自行組裝工具參數。指定同一工作區與固定的 `--journal`。帳本會保留已完成批次和原文，應保存於受信的私人位置，以同一帳本處理回復與查核。

`model-budget-cases.json` 提供 0、4、5、9 段合成案例。保留原有文字校稿案例並把邊界案例加入資格。用 `observe_course_host.py <案例 JSON>` 取得本機模型實測，再沿原補強工作送交同一範圍的資格證據。缺少量測、輸出不完整或呼叫計數不符時，資格驗證會阻擋候選。

領取後如果回執不明，使用同一領取輸出及帳本加上 `--reconcile`。這項操作只讀工具帳本。工具帳本可核對批次請求數與已保存的成果。Ollama 未回應的批次維持待查狀態，底座保留原逐字稿，前面已完成的校稿不會交付成完整結果。
