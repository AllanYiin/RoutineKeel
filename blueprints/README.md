# 工作流藍圖

此處保存待轉換的工作流藍圖。已安裝、可執行的流程位於
`../workflows/FLOW_<名稱>/`；設計入口位於 `../workflow_studio/`。

從設計到執行的順序為「讀取藍圖 → 建置候選工作流 → 在臨時工作區載入候選工作流並測試 → 驗收通過 → 安裝到正式工作區」。原始藍圖與候選工作流是兩個不同的檔案。

使用者的私人藍圖、素材與產出不會自動加入版本控制或 Release。
範例與測試資料位於 `../examples/blueprint-install/`。

RK-NEXT 的 Studio 會先在桌面對話顯示工作目標、具名交付、關鍵校閱點、業務規則與驗收案例。確認整份摘要後，`studio_export_blueprint` 將設計寫入 `blueprints/<工作流識別碼>/<SHA-256>.zip`。更改設計或更新附帶技能後要重新預覽；同一版可依指紋重取。只有明確選定的設計技能會收入 ZIP。匯出會用底座匯入器核對格式，尚未啟動任何正式工作流。
