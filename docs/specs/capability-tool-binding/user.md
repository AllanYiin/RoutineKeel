# 規格整理 v 1.2.0

## 非技術規格文件

### 能力與工具綁定

打開藍圖或已安裝的工作流時，你會看到每個步驟目前使用的工具、它是否在這個工作區可用，以及有沒有先前的實測證據。從 Studio 或終端查看同一份工作，使用的是同一套實際執行環境。

第一次安裝若遇到問題，提示會說明發生在哪裡。例如，資料夾無法暫存、選到了另一套 Python，和確實缺少一個工具，會分別顯示。能在另外一個可用暫存位置自行接續時，底座會先接續。需要你提供檔案或取得權限時，會保留進度並顯示可處理的事項。

### 缺件時會怎麼做

1. **比對可用替代工具。** 先找本機中已驗證、能交付同樣結果且符合原先資料範圍的工具。符合既有使用條件時接續驗證。
2. **準備可信的安裝方法。** 需要安裝時，查工具原廠的版本和準備方式。已在授權範圍內的套件會在隔離位置準備，先驗證再交給工作流使用。新下載或安裝需要你決定時，會列出來源與影響。
3. **補寫缺的工具。** 找不到適合的工具時，會先找可重用的程式或技能腳本，再準備小型轉接程式，實際測試它能否用指定資料產生預期結果。

例如課程字幕缺少抽音工具時，可以同時檢查本機可用的抽音程式、找需要的技能腳本，以及準備獨立的術語整理步驟。你在決定校稿模型期間，抽音或其他具備條件的部分仍能繼續。需要用到你的選擇的步驟會暫停，等你回覆後沿同一件工作繼續。

### 可接上的工具

| 你會用到的工具 | 工作流會如何處理 |
| --- | --- |
| 程式工具 | 用現有程式完成工作，例如以 faster-whisper 辨識課程語音。 |
| 技能 | 使用技能附帶的腳本，或把文字規則交給適合的模型，然後檢查實際成果。 |
| 已連線工具 | 在已授權的連線上呼叫指定工具，保存結果與收據。 |
| 模型要求使用的工具 | 模型只能從這個步驟已允許的工具提出請求，工具結果會送回模型以完成後續工作。 |
| 終端工具 | 呼叫本機程式，例如用 ffprobe 讀取媒體資訊，並檢查結果格式。 |
| 宿主文字模型 | 模型逐步顯示文字、記錄實際使用範圍，完成後送回工作流。 |

### 你需要決定的時候

對話會先顯示要決定的事項，包含資料會去哪裡、工具費用、使用哪個版本及這次允許的範圍。例如 9 段字幕需要 3 批本機校稿時，你會看到本次最多 3 次。確認後才送出。送出後連線中斷時，先查同一筆結果。未確認結果時，會保留前面成果與已知的進度。

正常進度用中性色，等待決定用琥珀色，明確錯誤用深紅色，每種都配文字標籤。終端可以直接讀相同提示，並以一則文字選擇。來源、檢查細節和可以本機開啟的附件，可依需要展開。

### 怎樣算完成

每個必要步驟都有可用工具與實測證據，整份工作流通過獨立試做和安裝前檢查。安裝收據說明哪些案例已驗證，哪些留到正式素材。安裝後工具失效時，系統會標出受影響的步驟，沿原工作安排補強，能使用的辨識稿和其他成果可接著用。
