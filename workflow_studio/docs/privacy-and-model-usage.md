# 對話資料與模型用量

桌面宿主使用自己的模型整理問題、草擬設計與解釋修訂。Studio 在本機保存訪談版本、來源參照、使用者的實際答覆及其對應問題。設計草稿經確認才能成為藍圖。模型產生的文字應逐段顯示，串流中斷時可回到上一個已保存版本。

附件先顯示本機預覽或可辨識的格式資訊。匯出前核對具名交付、驗收案例、技能檔及來源版本。驗收案例應使用可分享的測試資料，獨立驗收檔留在本機。工作流使用模型、網路或外部工具時，宿主需有可查核的能力與授權紀錄。

流程實際呼叫 API 的用量、對話宿主的用量，以及隔離測試提供的模擬資料各自標示。沒有可靠收據時顯示未知。[訪談與來源操作](host-conversation.md)
